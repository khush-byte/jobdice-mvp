# JobDice — MVP фронтенда

Демонстрационный интерфейс платформы поиска работы и найма JobDice.
Реализован на **Next.js 14 (App Router) + TypeScript + Tailwind CSS**,
работает полностью на статичных данных (`lib/data.ts`) — без бэкенда,
базы данных и внешних API.

## Запуск

Требуется Node.js 18.17+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Продакшн-сборка:

```bash
npm run build
npm run start
```

## Что реализовано

| Раздел | Страница | Комментарий |
|---|---|---|
| Главная | `/` | Ценностное предложение, пример досье компании, подборка вакансий |
| Поиск вакансий | `/jobs` | Фильтры по формату работы и уровню, сортировка по Match Score / дате |
| Карточка вакансии | `/jobs/[slug]` | Расшифровка AI Match Score, верифицированные требования, воронка найма |
| Профиль компании | `/companies/[slug]` | Составной рейтинг, история компании, слепые отзывы, прозрачные метрики найма |
| Цифровое досье кандидата | `/candidates/[slug]` | Подтверждённый опыт, навыки с верификацией, портфолио, отзывы |
| Конструктор резюме | `/resume-builder` | Форма с живым превью, генератор сопроводительного письма (сценарий на статичных данных) |
| Кабинет работодателя | `/dashboard/employer` | Таблица вакансий с воронкой, ATS-канбан по этапам найма |
| Кабинет соискателя | `/dashboard/candidate` | Отклики, сохранённые вакансии, карьерный трек, релокационный модуль |
| AI-ассистент | виджет на всех страницах | Плавающая кнопка со сценарием диалога |

Все цифры, профили и отзывы — вымышленные демонстрационные данные
в `lib/data.ts`. Реальный AI-скоринг, чат-бот, эскроу и верификация
через госреестры в этой версии не подключены — интерфейс показывает,
как они должны выглядеть и вести себя.

## Структура проекта

```
app/
  page.tsx                       — главная
  jobs/page.tsx                  — список вакансий
  jobs/[slug]/page.tsx           — карточка вакансии
  companies/[slug]/page.tsx      — профиль компании
  candidates/[slug]/page.tsx     — досье кандидата
  resume-builder/page.tsx        — конструктор резюме
  dashboard/employer/page.tsx    — кабинет работодателя
  dashboard/candidate/page.tsx   — кабинет соискателя
  layout.tsx, globals.css        — общий layout, шрифты, дизайн-токены
components/                      — переиспользуемые UI-блоки
lib/data.ts                      — типы и статичные (mock) данные
```

## Дизайн-система

Визуальная концепция — «цифровое досье / реестр доверия»: ledger-стиль
(тонкие линии-разделители вместо карточек с тенями), печати верификации
(`VerifiedBadge`), составные рейтинги с разбивкой по источникам.

- Шрифты: Source Serif 4 (заголовки) + IBM Plex Sans (интерфейс) + IBM Plex Mono (цифры/метки)
- Цвета: бумажный фон `#F4F5F0`, чернильный текст `#161C2E`, зелёная печать подтверждения `#2F6F52`, латунный акцент `#C7962C`, глиняный предупреждающий цвет `#AE4E37`
- Все цвета/шрифты вынесены в `tailwind.config.ts` — их легко поменять под фирменный стиль

## Дальнейшие шаги (см. рекомендации по стеку)

Этот репозиторий закрывает только фронтенд. Для рабочего MVP по этапу 1
дорожной карты (0–6 месяцев) дальше потребуется:

1. **Backend**: модульный монолит на NestJS или Django (профили, вакансии, отклики, отзывы) — резать на микросервисы позже.
2. **База данных**: PostgreSQL + Elasticsearch/OpenSearch для поиска, Redis для кэша/очередей, S3-совместимое хранилище для медиа.
3. **Аутентификация**: OAuth (Google/LinkedIn) + email/password.
4. **AI-модуль**: отдельный сервис на FastAPI — интеграция с LLM API для чат-бота и генерации писем, эмбеддинги (pgvector) для матчинга.
5. **Замена мок-данных** в `lib/data.ts` на запросы к API (`fetch`/React Query) постранично.

## Известные ограничения демо-версии

- Нет реальной формы логина/регистрации.
- Кнопки «Откликнуться», «Разместить вакансию» и генератор письма не сохраняют данные — состояние сбрасывается при перезагрузке страницы.
- ATS-канбан не поддерживает drag-and-drop, только кнопки «вперёд/назад».
